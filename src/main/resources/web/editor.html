🔀 조건문

if player is op: message {player} &c관리자 else: message {player} &7일반

조건 목록:

player is opOP 여부
player has permission "node"권한
player gamemode is survival게임모드
player health > 10체력 비교
player level > 5레벨 비교
player has DIAMOND아이템 소지

📦 변수

변수는 플레이어별로 메모리에 저장됩니다 (서버 재시작 시 초기화).

set {score} to 0 add 1 to {score} remove 1 from {score} delete {score}

조건에서 사용:

if {score} > 10: broadcast &6{player} 점수 10 돌파! if {score} equals 0: message {player} 아직 점수가 없습니다 if {score} is set: broadcast 변수 존재

메시지에서 사용: broadcast 점수: {score}
